### 🚀 Sobre o Projeto
O **Bloc Destructor** é um jogo clássico de arcade desenvolvido em Python utilizando a biblioteca **Pygame**. O objetivo do jogador é controlar a plataforma na parte inferior da tela para rebater a bola e destruir todos os blocos verdes antes que a bola caia, acumulando pontos a cada bloco eliminado.

---

### ✨ Funcionalidades
* **Geração Dinâmica de Blocos:** Os blocos são distribuídos e renderizados automaticamente na tela através de matrizes e funções matemáticas.
* **Sistema de Colisão:** Detecção de colisão precisa entre a bola, as paredes, a barra do jogador e os blocos.
* **Placar de Pontuação:** Acompanhamento em tempo real dos blocos destruídos e condição de vitória/fim de jogo.
* **Controles Simples:** Movimentação fluida utilizando as setas direcionais do teclado (`←` e `→`).

* **Biblioteca Gráfica:** Pygame
